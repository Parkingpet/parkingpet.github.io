# Jules Agent Information System

This directory stores Jules learning entries and agent information.

## Structure

- **palette.md** - Main learning palette with dated entries
- **agents.md** - Agent profiles and configurations
- **index.md** - Quick reference index

## Entry Format

### Learning Entry (palette.md)
```markdown
## YYYY-MM-DD - Title
**Learning:** What was learned
**Action:** What to do next time
```

### Agent Entry (agents.md)
```markdown
## Agent Name
- **Role:** Description
- **Capabilities:** List of capabilities
- **Last Updated:** YYYY-MM-DD
- **Status:** Active/Inactive
```

## 2024-03-04 - Avoid Array Allocations and Math.sqrt in Hot Loops (requestAnimationFrame)
**Learning:** Using `Array.prototype.slice` inside `requestAnimationFrame` creates massive Garbage Collection (GC) churn. For 50 particles at 60fps, `particles.slice(i+1).forEach` creates 3,000 new arrays per second. Additionally, using `Math.sqrt` for distance calculations is an expensive operation when called thousands of times per frame.
**Action:** Replace array methods (`forEach`, `slice`) with standard nested `for` loops in hot animation paths. Optimize distance checks by comparing the squared distance (`dx*dx + dy*dy < radius*radius`) instead of calculating the exact distance with `Math.sqrt`. Always store and cancel `requestAnimationFrame` IDs in `useEffect` cleanup to prevent memory leaks.
